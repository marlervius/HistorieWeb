# Kildematrise 1.1 – Hva kan vi vite om fortiden?

**Status:** R1 – produksjonsklart grunnlag; hoved- og separat kildekontroll er innarbeidet.

Matrisa skiller mellom historisk funn, forsknings-/oppslagsstøtte, redaksjonell syntese og hva kilden ikke kan bevise. «Direkte» betyr at kilden selv oppgir eller viser forholdet; «indirekte» betyr at påstanden er en avgrenset tolkning av dokumenterte funn; «syntese» betyr at redaksjonen sammenholder flere kilder og må formulere seg med forbehold.
