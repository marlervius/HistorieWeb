# Medieregister

## `public/og.png`

- Funksjon: sosial forhåndsvisning for læreverket.
- Opphav: generert med OpenAI ImageGen 17. august 2026 for dette prosjektet.
- Motiv: abstrakte lag- og tidslinjemotiver; bildet er ikke en historisk kilde og framstiller ingen konkret hendelse, gjenstand eller geografi.
- Tekst kontrollert: «Historie i sammenheng» og «Historie VG2».
- Publiseringsstatus: kvalitetssikret for offentlig bruk i prosjektet.


## Kildeverksted 2.2

- Valg: ingen nye bilder, kart, faksimiler eller andre mediefiler.
- Elevmaterialet består av tekstlige, egne beskrivelser av materielle spor med kilde-ID-er, kildeopphav og rettighetsstatus i content/chapters.ts.
- Publiseringsregel: ingen mediekomponent eller offentlig filreferanse tas inn før filen finnes i public/, alternativtekst, opphav, lisens og kreditering er kontrollert.
